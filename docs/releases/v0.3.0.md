Agentmesh's first public release connects Claude Code and Codex CLI sessions across trusted machines.

## Start a network

On the first machine, run `agentmesh setup` and `agentmesh invite create`.
On the next machine, run `agentmesh join` and paste the invitation code.
Then keep using `claude`, `tclaude`, `codex`, or `tcodex`.

## Included

- Expiring, single-use invitations with mutual enrollment and automatic member synchronization.
- Per-session MCP mailboxes, a cross-machine directory, direct messages, replies, and local group broadcasts.
- Automatic Claude inbox attachment and Codex thread attachment on the first turn.
- Encrypted iroh transport, persistent SQLite inbox/outbox, retries, and duplicate prevention.
- Configuration merging, private backups, scoped communication-tool permissions, and safe daemon upgrades.

## Validation and scope

22 local regression checks passed, with independent review.
Real tclaude and official Codex models passed automatic attachment, idle wake, read, reply, and acknowledgement checks.
TCodex passed real MCP communication, automatic thread binding, and queue submission; its configured model returned upstream HTTP 429 during model verification.
Native Codex reminders use the normal shared CLI daemon; standalone stdio App Servers and `--no-daemon` sessions are outside that path.
Network members must be trusted machines.
Messages do not grant shell or file permissions.

Download the archive matching your OS and architecture, extract it, and put `agentmesh` on your PATH.
Verify the archive against `SHA256SUMS`.
