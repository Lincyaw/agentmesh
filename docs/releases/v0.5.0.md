# Agentmesh v0.5.0

Enroll a new machine with one installer command and one private bootstrap invitation.
The installer downloads and checks a native binary, configures all four supported
CLIs, joins the private relay network, publishes a dedicated controller workspace,
and installs a user service where supported.

- `invite create --bootstrap` packages an existing single-use invitation with private
  relay configuration. It never adds relay credentials to public peer tickets.
- `join` recognizes bootstrap invitations and grants the inviting machine access to
  `~/agentmesh-workspace` only after authenticated enrollment succeeds.
- `--relay-resolve IP` pins the relay hostname natively while preserving TLS checks;
  no Python DNS helper or external DNS is needed.
- Bootstrap reruns preserve existing installations and reject conflicting settings.
- User services support systemd and launchd, with managed startup and explicit readiness.

This release also includes v0.4's nine remote workspace and job MCP tools, durable
command deduplication and output, explicit per-peer permissions, and private-only
transport defaults. Native harness file and shell tools remain local.

Bootstrap codes contain a long-lived shared relay credential alongside expiring
network admission. Keep codes private. Commands execute with the remote Unix user's
permissions; the workspace is not an OS shell sandbox.

See the onboarding and validation records for supported platforms and test evidence.
