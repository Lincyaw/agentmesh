# Agentmesh launch animation

A silent, 20-second product promo for developers running coding sessions across multiple machines.
The viewer should understand that one invitation connects their machines and makes ordinary CLI sessions reachable.
No paid audio, fabricated performance numbers, or screenshots of private sessions are used.

The central picture keeps the same three machine panels throughout the animation.
An invitation travels to a new machine, connection paths appear only after enrollment, a private message traverses one path, and a broadcast splits across the network.

| Time | Situation and operation | Result and hold |
| --- | --- | --- |
| 0–5 s | Reveal two existing network members and a third machine with a local CLI session. | The new machine is visibly outside the shared directory. |
| 5–10 s | Move a single-use invitation from the first machine to the new machine; show `agentmesh join`; draw authenticated connections after arrival. | All three panels join the same directory. |
| 10–15 s | Move a message from Claude on the laptop to Codex on the server; return a reply along the same path. | The inbox and reply states light up at arrival. |
| 15–20 s | Split one outgoing message along two paths to a named group. | Multiple recipients light up; hold the connected network and four CLI names. |

Lime means a connected route or delivered message.
Muted lines mean an available but inactive route.
Machine identity is always written beside its panel.
The animation is illustrative; labels are example devices, not captured user data.

Every frame is reconstructed from scene time.
Review includes forward/backward seeks, the join-to-connected boundary, a moving message mid-path, the broadcast result, and a small-screen reading check.
